ratified estate it is four propositions, and only one of them lands.

## 2. The home, and the home that looked right

The plan named `proxy.admission_state_source`, and the measurement agrees — but for a reason
the plan did not give, and against a neighbour that is more attractive than the plan said.

`proxy.admission_currency_gate` already holds **ten** `tests/integration_async#admission_currency_serving_test::…`
selectors. Nine of the ten rows above are its siblings in one file, and appending them there
would have been one line of diff with every sibling already present. It is refused because
**that unit carries no theorem** — it is one of the twenty — so the controls would have moved
out of the census into a unit no theorem supports. That is a re-filing dressed as a discharge.

`proxy.admission_state_source` resolves to **THM-0129** (`supported_by`), is `critical`, and
declares `test_features = ["redis_replay"]`. Measured: `cargo test -p mcp-re-proxy --features
redis_replay --test integration_async -- --list` reports **168** tests and all four registered
selectors appear in it, so the unit's declared lane really does select them.

## 3. The four that landed, each against quoted ratified text

All quotations whitespace-normalised substring-matched against
`verification/policy/theorems.toml` and `verification/policy/verification.toml`. 22/22 matched;
nothing was paraphrased.

* `an_expired_authentic_record_…` — THM-0129: *"the CURRENTNESS CEILING refuses a genuine record
  RESTORED after it was superseded"* and *"A reachable store that answers with a record the
  deployment will not act on is a definitive non-admission, not an outage"*. The unit's own
  description carries the second clause verbatim in the lower case: *"a reachable store that
  answered with a record this deployment will not act on is a definitive negative rather than an
  outage"*.
* `restoring_a_revoked_workloads_…` — THM-0129: *"or keep a revoked workload in service by
  restoring the bytes from before its revocation"*. The unit already holds the source-level twin,
  `restoring_an_older_publication_after_a_revocation_is_refused`.
* `a_revocation_on_the_shared_source_…` — THM-0129: *"An authoritative admission state accepted by
  the enforcement point is authenticated as issued by the configured admission authority, bound to
  the workload and to the admission generation and status, and current within the deployment's
  declared revocation-currentness budget."* The replica that never saw the workload accepts a state
  bound to it whose STATUS is revoked; the unit's source-level twin is
  `a_signed_revocation_is_state_and_not_a_failure_to_obtain_state`.
* `a_current_admitted_workload_is_served` — the non-vacuity partner, the serving-path instance of
  `a_current_record_from_the_configured_authority_is_state`. Without it the three refusals above
  cannot distinguish a working gate from one that refuses everything.

Each is a STRICT DECOMPOSITION of a row the unit already measures at the source, and what it adds
is that the enforcement point acts on the state the source hands it. No theorem fingerprint field
moved; the only theorem-level effect is that `proxy.admission_state_source`'s battery grew.

## 4. NP-160's residue — the caller's assertion

THM-0129's ratified scope refuses the three retained rows in one sentence:

> Says nothing about the assertion the CALLER presents (ASM-0012), nor about whether the call
> matches the state — that is THM-0004.

The nearest claim is **THM-0006**, *presenter binding*, whose owner is
`http_profile.admission_currency` — evidence class `proved`. Joining a serving-path integration
control to a Verus battery substitutes a probe class, which ADR-MCPRE-068 N4 forbids. There is no
tested unit in the estate whose proposition is *the presented assertion is authentic and bound to
its presenter*, and creating a theorem is outside this slice's authority.

## 5. NP-188 — the call/state comparison

Same sentence, the other clause: *"nor about whether the call matches the state — that is
THM-0004."* `a_generation_ahead_of_the_authority_is_refused` compares a caller-claimed generation
against the published one. It is not a state property, and THM-0004 is proved rather than tested.

This is the record's sharpest measurement: the four that landed and this one sit in one file, one
module, with one helper set, and the ratified line between them runs straight through the middle of
that file. Filing the record whole would have carried this row across it.

## 6. NP-189 — admission is not authorization

`an_admitted_workload_is_still_refused_by_a_denying_policy` is in the admission carrier and is not
an admission proposition. THM-0129 never mentions policy. THM-0040 does, but it is a claim about
`PdpDecisionEvaluator::evaluate` and an authenticated decision document, while this control installs
an ADR-MCPRE-065 Slice 1 evaluator that refuses everything. The unit holding the Slice 1 serving
battery, `proxy.authorization_capability`, carries no theorem.

## 7. NP-190 — a measurement, on an axis and in a lane

Two independent refusals, and either is sufficient.

**The axis.** The control's assertion is a wall-clock interval against `DECLARED_P_MS`, printed as
the number the budget could honestly be set to. THM-0129 says *"AVAILABILITY is not claimed."*
Registering a propagation-delay measurement under it widens the ratified claim along the
latency/propagation axis, which this slice may not do.

**The lane.** The file is `#![cfg(feature = "redis_replay")]` and the control's first statement is

```rust
let Some(url) = redis_url() else { eprintln!("SKIP …"); return; };
```

so even inside its own feature lane it reports success without measuring anything unless
`MCP_RE_TEST_REDIS_URL` is set. A registered member that green-passes without executing is exactly
the false green `scripts/slo_invocation_gate.py` exists to prevent, one layer up. It is not
evidence, and it must not be recorded as some by a unit whose other members are real.

## 8. What was NOT done

No theorem fingerprint field edited; no `[[theorem]]`, `[[assumption]]` or trust-boundary row added;
no unit `description` amended; no unit `paths` widened; no `not-evidence` family created; no
`direct_consequence_severity` lowered; `ratified_as` set nowhere. Units without a theorem: 20 before,
20 after.
